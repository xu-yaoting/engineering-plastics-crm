# Daily Workflow Checklist — Engineering Plastics CRM

**用途：** 每日 CRM 操作手动验证清单。数据无价，建议每次重要操作前/后过一遍。

---

## 一、客户与联系人

### 新建公司
- [ ] 左侧导航 → 公司
- [ ] 点击「新增」按钮
- [ ] 填写：公司名称、行业、国家/地区、网站（可选）
- [ ] 保存 → 确认 Toast 显示成功
- [ ] 公司出现在列表中

### 编辑公司
- [ ] 点击公司行 → 进入详情页
- [ ] 点击「编辑」 → 修改字段（名称、行业等）
- [ ] 保存 → 确认变更生效

### 新建联系人
- [ ] 在公司详情页 → 联系人标签 → 新增
- [ ] 填写：姓名、邮箱、电话、职位
- [ ] 保存 → 确认出现在联系人列表

### 编辑联系人
- [ ] 点击联系人 → 编辑面板
- [ ] 修改字段（含复选框字段）
- [ ] 保存 → 确认无报错、变更生效

---

## 二、询盘与报价

### 新建询盘
- [ ] 左侧导航 → 询盘 → 新增
- [ ] 选择公司/联系人
- [ ] 填写：品名、规格、数量、目标价格
- [ ] 保存 → 确认列表出现

### 创建报价
- [ ] 在询盘详情 → 创建报价
- [ ] 填写报价明细（单价、数量、条款）
- [ ] 保存 → 确认报价状态

### 查看报价 PDF
- [ ] 报价详情 → 下载/预览 PDF
- [ ] 确认 PDF 排版正常、金额计算正确

---

## 三、订单与执行

### 创建订单
- [ ] 在报价详情 → 转为订单（或手动新建）
- [ ] 核对：客户、产品、数量、金额
- [ ] 保存 → 确认订单状态

### 订单状态推进
- [ ] 确认 → 生产中 → 发货中 → 已完成
- [ ] 每次状态变更保存后确认

---

## 四、库存

### 查看库存仪表板
- [ ] 左侧导航 → 库存
- [ ] 确认产品列表加载正常
- [ ] 确认库存数据与预期一致

### 产品管理
- [ ] 新增产品：填写 SKU、品名、规格、单位、品类
- [ ] 确认 SKU 可手动编辑（非自动生成）
- [ ] 保存 → 确认出现在产品列表
- [ ] 编辑产品：名称、SKU、规格等
- [ ] 保存 → 确认变更生效
- [ ] 软删除：确认产品从活跃列表移除

### 入库
- [ ] 库存 → 入库操作
- [ ] 填写：产品、数量、批次号（可选）
- [ ] 保存 → 确认库存数量增加

### 出库
- [ ] 库存 → 出库操作
- [ ] 填写：产品、数量、用途/订单号
- [ ] 保存 → 确认库存数量减少

### 库存调整
- [ ] 库存 → 调整操作
- [ ] 填写：产品、调整类型（盘盈/盘亏）、说明
- [ ] 保存 → 确认台账记录准确

---

## 五、回款与发货

### 记录回款
- [ ] 左侧导航 → 回款 → 新增
- [ ] 填入：客户、金额、日期、方式
- [ ] 保存 → 确认回款记录

### 创建发货
- [ ] 左侧导航 → 发货 → 新增
- [ ] 填写：订单关联、客户、产品、物流信息
- [ ] 保存 → 确认发货记录

### 发货详情
- [ ] 点击发货记录 → 查看详情
- [ ] 确认物流追踪信息

---

## 六、活动与任务

### 记录活动
- [ ] 在客户/联系人的活动时间线 → 新增
- [ ] 类型：电话 / 邮件 / 会议
- [ ] 填写内容和纪要
- [ ] 保存 → 确认时间线更新

### 任务管理
- [ ] 左侧导航 → 任务
- [ ] 新增任务：标题、关联对象、截止日期
- [ ] 完成任务 → 标记完成

---

## 七、系统

### 切换语言
- [ ] 右上角用户菜单 → 语言切换
- [ ] 简体中文 / English 切换后确认界面语言

### 修改个人设置
- [ ] 右上角用户菜单 → 设置
- [ ] 修改姓名等配置
- [ ] 保存 → 确认侧边栏用户菜单同步更新

### 数据库备份
- [ ] 终端执行：`npm run backup`
- [ ] 确认 `backups/` 目录生成 `.db.gz` 文件
- [ ] 确认 `.sha256` 校验文件存在

### 数据库恢复（回滚用）
```bash
# 先关闭 CRM
# 然后执行：
npm run restore -- --confirm /path/to/crm-YYYYMMDD-HHMMSS.db.gz
```

---

## 八、启动/关闭

### 每日启动
- [ ] 双击桌面 `CRM.app`
- [ ] 确认终端输出显示 API OK + App Ready
- [ ] 浏览器确认 http://127.0.0.1:5173 正常加载
- [ ] 快速检查：`curl http://127.0.0.1:3001/api/health`

### 关闭
- [ ] 终端 Ctrl+C 停止服务
- [ ] 可选：执行 `npm run backup` 后关闭

---

## 故障排查

| 症状 | 检查项 |
|---|---|
| 端口被占用 | `lsof -ti :3001`, `lsof -ti :5173` → kill |
| API 返回 500 | 检查 `logs/start-crm.log` 或终端输出 |
| 前端空白页 | F12 控制台检查网络/JS 错误 |
| 数据库异常 | 从最近的备份恢复 |
| 配置丢失 | 检查 `.env` / `.api-key` 是否存在 |
