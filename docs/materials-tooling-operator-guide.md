## 2. 物料主档

### 创建物料
1. 进入 **Materials** tab → 点击右上角 `+` 按钮
2. 填写：编码、名称、分类、规格、单位（固定单位，不支持换算）、仓库/货位、安全数量
3. 点击 **Create** 保存

### 当前数量
由已执行单据的库存流水实时计算，不可直接编辑。

### 安全数量预警
当库存低于安全数量时，Overview 低库存提醒和 Materials tab 数量高亮显示。

## 3. 单据工作流

### 通用流程

```
Draft → Submit → Pending Approval
                    ├─ 采购申请 Approve → Approved
                    ├─ 其他单据 Approve → Pending Execution → Execute → Executed → (上传签字件) → Completed
                    └─ Reject → 退回 Draft
                          (可修改后重新提交)
Withdrawn: 申请人在任何非终态可撤回
```

### 创建单据
1. 进入 **Documents** tab → 点击 `+` 按钮
2. 选择单据类型（PR/GR/MI/MR/MS/CA/TM）
3. 填写一行或多行物料明细（物料、固定单位数量、采购单价等）；采购单可直接手写供应商名称（可留空），再按需填写合同号/发票号
4. 点击 **Create**

### 提交与审批
- 提交后系统冻结不可变版本快照 + 生成申请版 PDF
- 审批通过生成审批版 PDF，单据进入待执行
- 申请人不能审批自己的单据

### 执行
- 执行前重新校验库存，禁止负库存
- 执行后在库存流水中追加记录（不可逆）
- 禁止重复执行

### 签字件闭环
1. 下载审批版 PDF（A4 打印）
2. 线下签字
3. 扫描/拍照后在单据详情页上传 Signed Copy
4. 状态变为 Completed

## 4. 月度台账

### 查看
- **Ledger** tab：选择月份，查看期初/入库/出库/结存量价
- `viewPrices` 控制金额列可见性

### 导出
- Excel 按钮 → 下载 `.xlsx`（按仓库工作表分组）
- PDF 按钮 → 下载 A3 横向 PDF

### 期结
1. 确保本月所有单据已执行或已作废
2. 在 Ledger tab 点击 Close
3. 关闭后禁止创建/修改本月单据
4. 管理员可通过 Reopen 重新打开（需填写原因）

## 5. 工装管理

### 工装主档
- **Tooling** tab：查看/创建工装资产
- 每个工装有独立编码、状态、保管人、位置
- 终态（已报废/已遗失）不可修改非备注字段

### 状态流转

| 动作 | 源状态 → 目标状态 | 保管人 |
|---|---|---|
| Issue (领用) | in_stock → in_use | 设置目标保管人 |
| Loan (借出) | in_stock → loaned | 设置目标保管人 |
| Return (归还) | in_use/loaned → in_stock | 清空 |
| Transfer (转交) | 任意非终态 → 保持 | 至少改保管人或位置 |
| Repair (送修) | in_stock/in_use → under_repair | 清空 |
| Repair Completion (修复完成) | under_repair → in_stock | 清空 |
| Disposal (报废) | 任意非终态 → disposed | 清空 |
| Loss Report (遗失) | 任意非终态 → lost | 清空（需原因 + 照片） |

### 工装流转
1. 创建 `tooling_movement` 类型单据
2. 提交 → 审批 → 执行
3. 执行后状态自动变更，写入不可变历史

## 6. 更正与作废

### 已执行耗材单据
1. 管理员在单据详情页点击 **Void & Replace**
2. 填写作废原因
3. 系统执行原子反冲（库存量回退）+ 创建新编号替换单
4. 原单标记 `voided`，新单标记 `draft`

### 已执行工装单据
1. 管理员在工装单据详情页点击 **Void & Replace**
2. 填写作废原因
3. 系统执行工装反冲（状态/保管人回退）+ 创建新编号替换单
4. 同一工装后续已有其他流转记录时，禁止反冲

### 禁止操作
- 不允许直接修改或删除已执行单据
- 不允许部分执行
- 不允许直接编辑当前数量或工装状态

## 7. 附件安全

- 所有附件私有存储，不在公开路径暴露
- 下载需要经过认证和权限检查
- 价格/合同/发票附件分类受 `viewPrices` 权限保护
- 普通成员看不到敏感附件的下载入口

## 8. 期初导入

### 前置条件
- 已创建物料主档（编码匹配）
- 已确定切换月份（如 2026-07）

### 导入步骤
1. 准备 XLSX 文件，必填列：`code`, `unit`, `quantity`；可选列：`unit_price`, `supplier_code`, `supplier_name`
2. 进入 **Materials** tab → 使用右上角导入功能
3. 上传文件 → 预览匹配结果
4. 确认导入 → 整批创建 `opening_balance` 类型流水；任何未知物料、重复编码、单位不一致、非法价格或已关账月份都会阻止整批写入
5. 行内同时提供有效供应商和正数 `unit_price` 时，额外创建不改变库存的 `reference_purchase` 议价历史
6. 导入完成后可在 Ledger tab 查看期初数量，并在价格历史中核对可信采购批次

## 9. 备份与恢复

### 创建备份
```bash
npm run backup
```
生成 `backups/crm-YYYYMMDD-HHMMSS.tar.gz`，包含：
- `crm.db`（一致性 SQLite 快照）
- `data/materials-tooling/`（附件目录，如存在）

### 恢复备份
```bash
# 先关闭 CRM 服务
npm run restore -- --confirm /path/to/backup.tar.gz
```
支持新旧格式：
- `.tar.gz`：恢复数据库 + 附件
- `.db.gz` / `.db`：仅恢复数据库（旧版兼容）

恢复脚本会先验证压缩包、可选 SHA-256 校验文件及 SQLite 完整性，全部通过后才替换现有数据库；验证失败不会删除当前数据库或附件。替换前还会自动创建当前数据库的预恢复备份。

## 10. PDF 文档

| 版式 | 生成时机 | 内容 |
|---|---|---|
| Application PDF | 提交审批时 | 冻结的申请数据，含签字区 |
| Approved PDF | 审批通过时 | 含线上审批记录的冻结数据 |

- 工装流转单额外显示工装信息框（编号/名称/动作/状态转变/保管人）
- 价格脱敏：无 `viewPrices` 权限时隐藏采购金额和供应商信息
- 签字区根据单据类型：工装显示"移交人/接收人"，耗材显示"仓管/领用人"

## 11. 不支持的场景（第一期范围外）

- 通用记账或会计估值
- 应付账款或付款对账
- 税务或发票认证
- 自动招投标或供应商比价
- 生产计划、BOM、工单或 MRP
- 与 CRM 客户、销售订单或现有库存表的关联
- 第三方具有法律效力的电子签名
- 多级审批链
- 单位换算（如箱转个）
- 多层物料分类
- 部门或金额驱动的动态审批路由

## 12. 常见问题

### 为什么不能创建某类型单据？
检查 Settings 中该类型的审批人配置。如未配置，需管理员先设置。

### 为什么期结失败？
期结会检查：
1. 本月是否有待审批单据
2. 本月是否有待执行单据
3. 本月已执行单据是否需要上传签字件
4. 库存是否有负数

全部解决后重试。

### 为什么无法作废某工装单据？
该工装在此次流转后已有其他流转记录。先作废后续记录才能作废本次。

### 附件上传失败？
支持格式：PDF、JPG、PNG、Excel、Word。单文件上限已配置（默认较大）。
